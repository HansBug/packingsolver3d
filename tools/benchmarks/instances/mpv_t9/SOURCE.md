# MPV generator, type 9, n = 30

The twenty CSV files in this directory are ten three-dimensional bin packing instances produced by the official instance generator of Martello, Pisinger and Vigo ("The three-dimensional bin packing problem", *Operations Research* 48(2), 2000, with the later general-packing code by Martello, Pisinger, Vigo, den Boef and Korst). The generator is `test3dbpp.c` from the "General 3D Bin-packing Problem" entry of David Pisinger's code page, http://hjemmesider.diku.dk/~pisinger/codes.html (files `new3dbpp/3dbpp.c`, `new3dbpp/test3dbpp.c`, `new3dbpp/readme.3dbpp`). The code page states that the codes are free of charge for academic purposes; the generated numbers below are data, not code, and are redistributed here for benchmarking only.

Generator parameters: bin dimension 100 (a 100 x 100 x 100 bin), class (`type`) 9, `n = 30` items, replicates 1 to 10. Class 9 is the generator's "three-stage guillotine" class: three full bins are cut into the items, so every instance packs into exactly three bins and three is also the volume lower bound. The generator seeds `srand(n + replicate)` as the official `main` does with `v = 1..10`, so `MPV-GEN-T9-N30-R01` is seed 31 and `MPV-GEN-T9-N30-R10` is seed 40.

File format is PackingSolver's `box` CSV: `<id>_items.csv` has one row per item with `ID,X,Y,Z,COPIES` and the six `ROTATION_*` flags (only `ROTATION_XYZ` is set, i.e. the fixed-orientation variant), `<id>_bins.csv` has the single bin type. The benchmark tooling (`tools/make_benchmarks.py`) sets the bin copies to the number of items, which is what upstream's `--bin-infinite-copies` does.
