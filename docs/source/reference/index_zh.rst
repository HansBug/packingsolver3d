参考地图
========

* :doc:`solver_options/index_zh` —— ``box.solve`` 与 ``boxstacks.solve`` 的每个关键字参数及其背后的上游参数。
* :doc:`errors/index_zh` —— 异常层次及触发每个类的条件。
* :doc:`API 地图 </api_doc_zh>` —— 自动生成的逐模块 API 文档。
