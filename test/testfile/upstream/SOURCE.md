# Upstream test cases

These directories are verbatim copies of `data/box/tests/*` and `data/boxstacks/tests/*` from [fontanf/packingsolver](https://github.com/fontanf/packingsolver) at the commit pinned in `packingsolver3d/config/meta.py` (`__UPSTREAM_COMMIT__`), MIT licensed (see `LICENSE-packingsolver`). They are the instances upstream's own unit tests solve: `test/box/box_test.cpp`, `test/box/tree_search_test.cpp`, `test/boxstacks/optimize_test.cpp` and `test/boxstacks/sequential_onedimensional_rectangle_test.cpp`. `test/test_upstream_cases.py` solves each one through this package with the same parameters upstream uses and checks the result against `solution.csv` by the same objective comparison upstream's `Solution::operator<` applies.

`boxstacks/semi_trailer_truck_middle_axle_knapsack/solution_optimize.csv` is not an upstream file: upstream's gtest for that instance runs the `sequential_onedimensional_rectangle` sub-algorithm alone, whose reference (`solution.csv`) is empty, while this package can only reach `optimize()`. The file is the certificate written by upstream's own `packingsolver_boxstacks` executable, built from the pinned commit with the same options, on the same instance (`--linear-programming-solver highs`, no time limit); `test_upstream_cases.py` compares against it for that case.
