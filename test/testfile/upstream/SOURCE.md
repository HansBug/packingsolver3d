# Upstream test cases

These directories are verbatim copies of `data/box/tests/*` and `data/boxstacks/tests/*` from [fontanf/packingsolver](https://github.com/fontanf/packingsolver) at the commit pinned in `packingsolver3d/config/meta.py` (`__UPSTREAM_COMMIT__`), MIT licensed (see `LICENSE-packingsolver`). They are the instances upstream's own unit tests solve: `test/box/box_test.cpp`, `test/box/tree_search_test.cpp`, `test/boxstacks/optimize_test.cpp`, `test/boxstacks/sequential_onedimensional_rectangle_test.cpp` and `test/boxstacks/sequential_value_correction_test.cpp` (the last one, `boxstacks/knapsack_multi_bin_svc_zero_copies_item_type`, is the regression instance of fontanf/packingsolver#587 added at 9ae71316). `test/test_upstream_cases.py` solves each one through this package with the same parameters upstream uses and checks the result against `solution.csv` by the same objective comparison upstream's `Solution::operator<` applies.

The three `boxstacks/*_time_limit` directories are the cases `test/boxstacks/optimize_test.cpp` runs with a 3 s time limit (the reproducers of fontanf/packingsolver#570); the replay passes the same limit. Upstream's `test/box/reduction_test.cpp` and `test/boxstacks/reduction_test.cpp` (`data/*/tests/*merge_identical_items*`, `*remove_negative_profit_items*`) compare the `Reduction` class's output with `reduced_items.csv` / `reduced_bins.csv` structurally and never solve; this package does not expose the reduction, so those directories are not copied here.

`boxstacks/semi_trailer_truck_middle_axle_knapsack/solution_optimize.csv` is not an upstream file: upstream's gtest for that instance runs the `sequential_onedimensional_rectangle` sub-algorithm alone, whose reference (`solution.csv`) is empty, while this package can only reach `optimize()`. The file is the certificate written by upstream's own `packingsolver_boxstacks` executable, built from the pinned commit with the same options, on the same instance (`--linear-programming-solver highs`, no time limit); `test_upstream_cases.py` compares against it for that case.
